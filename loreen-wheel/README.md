# عجلة لورين التفاعلية

تطبيق PWA عربي للتابلت. لفّي العجلة بسحب الإصبع أو الماوس واتركيها تكمل بالدفع الطبيعي. الجوائز: ٤ خانات ٤٠٪، ٣ خانات ٥٠٪، خانتان ٦٠٪، وشريحة ذهبية ضيقة واحدة ١٠٠٪. شريحة ١٠٠٪ مساحتها ٦ درجات من ٣٦٠ (نحو ١٫٦٧٪ من مساحة العجلة).

باقة الجسم الكامل تشمل ٤ جلسات ليزر، سعرها ١٠٠ د.أ قبل الخصم. بعد اللفة يظهر الخصم والسعر النهائي المحسوب.

## التثبيت
- Android: افتحي الرابط في Chrome واضغطي «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- iPad: افتحي الرابط في Safari، اضغطي مشاركة، ثم «إضافة إلى الشاشة الرئيسية».

الاهتزاز يعتمد على دعم الجهاز والمتصفح. iPad Safari لا يتيح اهتزاز صفحات الويب عادة؛ يوجد صوت اختياري بديل.
