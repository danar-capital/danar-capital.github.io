# عجلة لورين التفاعلية

تطبيق PWA عربي للمس على أجهزة التابلت. يعمل بعد الزيارة الأولى دون اتصال. الجوائز: ٤٠٪ (٤ خانات)، ٥٠٪ (٣)، ٦٠٪ (٢)، و١٠٠٪ (خانة واحدة).

## التثبيت
- Android: افتح الرابط في Chrome واضغط «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».
- iPad: افتح الرابط في Safari، اضغط مشاركة، ثم «إضافة إلى الشاشة الرئيسية».

الاهتزاز يعتمد على دعم الجهاز والمتصفح. iPad Safari لا يتيح اهتزاز صفحات الويب عادة؛ يوجد صوت اختياري بديل.
